How alerts work

An alert fires only when a new location update arrives from the tracker that is outside the zone and this dashboard is open. If the phone is off, has no signal or tracking stopped, no update arrives and no alert can fire. Background push alerts need a server (Cloud Functions) and are not included.

Quick start

  1. On the phone on the bike: sign in → Tracker → Register this phone → Start tracking → Allow location.
  2. On your own phone: sign in → Live Map. A marker appears only after real updates arrive.
  3. Set a Safe Zone where the bike is parked.

Status meanings

  • LIVE – update received within your stale limit.
  • STALE – no update for a while; position may be old.
  • OFFLINE – no update for 5× the stale limit.
  • MANUAL – typed coordinates, not GPS.
  • DEMO – sample data only.

Limits

Phone browsers throttle web pages in the background. Accuracy depends on sky view and phone GPS. Only your own signed-in account can read or write data. This app does not track any other phone, number or vehicle.
